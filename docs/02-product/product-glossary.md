# Product Glossary

- **Project**: The top-level logical container for a software application within ForgeOS.
- **Workspace**: The physical, isolated execution environment (filesystem/container) where the project runs.
- **Task**: An atomic unit of work assigned to a specific agent or human.
- **Artifact**: A persistent file, document, or code block produced during the project lifecycle.
- **Agent**: An AI persona with a specific role, tools, and constraints.
- **Run**: A single, tracked execution of an agent workflow.
- **Execution**: The process of agents actively processing a task.
- **Approval**: A mandatory human gate required before high-risk actions proceed.
- **Human-in-the-loop**: The concept that ForgeOS requires human guidance and oversight, rather than full, unchecked autonomy.
- **Objective**: The high-level goal the AI organization is currently working toward.
- **Milestone**: A significant point in the project lifecycle (e.g., MVP release).
- **Requirement**: A defined business rule or feature constraint within the PRD.
- **Environment**: The deployment target (e.g., Dev, Staging, Production).
- **Repository**: The Git version control system storing the project's artifacts.
- **Deployment**: The act of releasing generated code to an environment.
- **Incident**: A production failure requiring SRE intervention.
- **Workflow**: The orchestrated sequence of steps agents take to complete a task.
- **Organization**: The collective team of specialized AI agents working on a project.
