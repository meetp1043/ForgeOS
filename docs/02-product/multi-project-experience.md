# Multi-Project Experience

As organizations scale, ForgeOS must support the management of multiple interconnected projects.

## Multi-Project Features

- **Project Switching**: A unified navigation menu to rapidly switch context between active projects.
- **Project Isolation**: Strict sandboxing ensuring that an agent in Project A cannot accidentally read or overwrite files in Project B.
- **Project Memory**: Long-term memory is scoped to the project, but organization-level memory can be enabled to share generic preferences (e.g., "We always use Tabs, not Spaces") across all projects.
- **Project Permissions**: Granular RBAC allowing a user to be an Administrator on Project A but only a Viewer on Project B.
- **Project Dashboards**: An aggregate organization-level dashboard showing the health, cost, and agent activity across all active projects simultaneously.
- **Project Lifecycle**: Support for archiving old projects, freezing their memory and storage to reduce costs, with the ability to instantly thaw and resume them later.
