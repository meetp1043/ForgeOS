# Operations Layer

The Operations Layer manages the deployment, reliability, and cost of the software.

## DevOps Engineer
**Responsibilities**:
- Design and implement CI/CD pipelines (e.g., GitHub Actions).
- Manage deployment environments (Dev, Staging, Prod).
- Automate infrastructure provisioning (Terraform, Dockerfiles).

## SRE Engineer (Site Reliability)
**Responsibilities**:
- Ensure system reliability and availability.
- Configure monitoring, logging, and alerting tools.
- Act as the first responder to production incidents.
- Formulate operational health reports and recovery strategies.

## Cloud Engineer
**Responsibilities**:
- Design specific cloud architectures (AWS, GCP, Azure).
- Manage networking (VPCs, Subnets), compute, and storage configurations.
- Ensure cloud security posture and infrastructure scaling rules.

## Cost Optimization Engineer
**Responsibilities**:
- Audit AI and cloud infrastructure costs.
- Recommend optimizations (e.g., model downgrades, instance resizing).
- *Constraint*: Must never optimize cost by blindly reducing system reliability, availability, or security.
