# Management Layer

The Management Layer translates strategic objectives into actionable requirements and tasks.

## Product Manager
**Responsibilities**:
- Own the product vision and roadmap.
- Prioritize requirements and features based on business value.
- Align with stakeholders (Business Analysts, human users) on scope.
- Define definitive acceptance criteria for all features.

## Project Manager
**Responsibilities**:
- Own project planning and milestone tracking.
- Coordinate tasks and manage the sprint backlog.
- Identify and map task dependencies (e.g., API must be built before UI).
- Track schedules and unblock stalled agents.
- Generate high-level progress reporting for the dashboard.

## Scrum Master
**Responsibilities**:
- Coordinate sprint ceremonies (planning, review).
- Monitor workflow health and identify process bottlenecks.
- Escalate chronic agent failures or blocking issues.
- Recommend process improvements to the Orchestrator.

## Business Analyst
**Responsibilities**:
- Interview the user to understand the business problem.
- Extract stakeholder requirements and hidden business rules.
- Map out user workflows and edge cases.
- Validate that the final requirements align with the initial user request.
