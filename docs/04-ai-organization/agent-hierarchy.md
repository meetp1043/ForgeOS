# Agent Hierarchy

The ForgeOS AI Organization is structured into distinct layers. Delegation flows downward; escalation flows upward.

## 1. Executive Layer
The strategic interface between the human user and the AI organization.
- **CEO Agent**: Understands high-level objectives and resolves strategic conflicts.

## 2. Management Layer
Translates strategy into actionable plans and manages execution.
- **Product Manager**: Owns the "What" and the "Why" (Requirements).
- **Project Manager**: Owns the "When" and the "Who" (Schedules, Assignments).
- **Scrum Master**: Owns the "How" (Process, Blockers).

## 3. Product / Business Layer
Bridges the gap between raw user intent and structured requirements.
- **Business Analyst**: Maps business workflows and extracts detailed rules.

## 4. Engineering Leadership
Sets technical standards and enforces architectural integrity.
- **Solution Architect**: Designs the system architecture and tech stack.
- **Engineering Manager**: Coordinates technical execution across specialist boundaries.

## 5. Engineering Specialists
The core executors who build the software.
- **Frontend Engineer**: Implements user interfaces.
- **Backend Engineer**: Implements APIs and business logic.
- **Database Engineer**: Designs schemas and migrations.
- **AI/ML Engineer**: Integrates external intelligence and model pipelines.

## 6. Quality Layer
Independent agents verifying the work of the specialists.
- **QA Engineer**: Writes and executes tests.
- **Code Review Engineer**: Audits code for maintainability and architectural compliance.
- **Security Engineer**: Audits code and infra for vulnerabilities.

## 7. Operations Layer
Manages the infrastructure and lifecycle of the deployed application.
- **DevOps Engineer**: Builds CI/CD pipelines.
- **SRE Engineer**: Monitors health and responds to incidents.
- **Cloud Engineer**: Provisions cloud infrastructure.
- **Cost Optimization Engineer**: Audits usage for financial efficiency.

## 8. Knowledge / Communication
- **Technical Writer**: Generates documentation for users and developers.
