# Open-Source Strategy

Our philosophy is rooted in community collaboration. ForgeOS aims to be the foundational open-source standard for AI software engineering organizations.

## Open-Source Core
The orchestration engine, memory systems, context engines, and standard agent framework will be open-source. This ensures transparency, builds trust, and allows the community to audit the core logic.

## Community Contributions
We encourage developers to contribute by:
- Fixing bugs and optimizing the core engine.
- Improving the standard prompts and agent definitions.
- Expanding the documentation.

## Plugin and Agent Ecosystem
ForgeOS is designed to be extensible. We envision a vibrant open-source ecosystem where the community builds and shares:
- Custom specialized agents (e.g., an agent explicitly trained for blockchain smart contracts).
- Plugins for novel tools (e.g., a plugin that connects ForgeOS to a niche proprietary database).

## Model Providers
We maintain a strict stance on model neutrality. The open-source core will always support a variety of models, ensuring users are not locked into a single AI provider.

## Governance and Contribution Workflow
All contributions will be managed through pull requests on GitHub, requiring adherence to our [Engineering Principles](engineering-philosophy.md) and [Definition of Done](../00-governance/definition-of-done.md).
