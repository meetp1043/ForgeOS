# Core Values

1. **Build responsibly.** Consider the long-term impact of the software we generate.
2. **Prefer truth over impressive output.** Accuracy and honesty are more valuable than hallucinated success.
3. **Human judgment matters.** AI is an accelerator, but humans hold the responsibility.
4. **Security is everyone's responsibility.** From the code we write to the AI we prompt.
5. **Quality is a feature.** Technical debt slows progress; we prioritize doing it right the first time.
6. **Simplicity is valuable.** Complexity should only be introduced when strictly necessary.
7. **AI should amplify people.** We aim to empower humans to achieve more.
8. **Never hide uncertainty.** If the AI is unsure, it must escalate and ask for help.
9. **Make systems understandable.** Black boxes are dangerous; systems must be explainable and auditable.
10. **Design for the future without overengineering today.** Build what is needed now while leaving doors open for tomorrow.
