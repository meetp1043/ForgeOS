# Git Conventions

- **Branching**: Use feature branches derived from `main`.
- **Commits**: Follow [Conventional Commits](https://www.conventionalcommits.org/).
  - e.g., `feat: add memory engine`
  - e.g., `fix: resolve database deadlock`
  - e.g., `docs: update architecture principles`
- **Pull Requests**: Keep them small and focused.
- **Merge Strategy**: Squash and merge or rebase. No merge commits.
