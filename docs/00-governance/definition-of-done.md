# Definition of Done

A task or feature is considered "Done" when:
1. The code is written and meets the Engineering Principles.
2. Unit tests and integration tests are written and passing.
3. The code is properly formatted and linted.
4. Secrets scan passes.
5. Relevant documentation and ADRs are created or updated.
6. The code is reviewed by another agent or human.
7. Deployed successfully to the testing environment (if applicable).
