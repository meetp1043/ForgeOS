# Architecture Decision Records (ADRs)

We use ADRs to capture significant architectural decisions.

## Process
1. Copy the template from `/templates/architecture-decision-record.md`.
2. Draft the ADR with Context, Decision, and Consequences.
3. Submit for review.
4. Once approved, merge it.
5. Never alter an approved ADR. If the decision changes, create a new ADR that supersedes the old one.
