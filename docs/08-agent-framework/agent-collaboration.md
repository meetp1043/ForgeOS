# Agent Collaboration

Collaboration is the orchestrated sequence of distinct agents interacting to deliver a complex feature.

## Collaborative Workflows

Agents collaborate primarily by passing artifacts and state through the Workflow Engine, rather than directly invoking each other.

### Example: Feature Delivery Pipeline

1. **Requirements**: The Business Analyst finalizes the PRD (artifact).
2. **Architecture**: The Solution Architect reads the PRD and generates an ADR (artifact).
3. **Implementation**: 
   - The Frontend Engineer reads the ADR and implements the UI (code changes).
   - The Backend Engineer reads the ADR and implements the API (code changes).
4. **Integration**: The QA Engineer pulls the code changes, writes integration tests, and executes them in an ephemeral environment.
5. **Review**: The Code Review Agent analyzes the diffs for style and OWASP violations.
6. **Deployment**: Upon QA and Review success, the DevOps Agent packages the artifacts and executes the deployment sequence.

## The Collaboration Rule
**Agents trust but verify.** 
The QA Agent does not blindly trust the Backend Agent's claim of "Success". It relies on the *Evidence* (test results) generated by the Backend Agent, and runs its own independent validation.
