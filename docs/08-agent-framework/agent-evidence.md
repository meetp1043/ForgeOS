# Agent Evidence

Evidence is the irrefutable proof that an agent actually accomplished what it claims to have accomplished. 

## The Zero-Trust Assumption
**Agents cannot invent evidence.**
An agent cannot simply output `{"evidence": "I ran the tests and they passed."}`. 
The Agent Framework requires cryptographic or systemic verification of evidence. 

## Sources of Verifiable Evidence

- **Build Output**: The actual `stdout`/`stderr` from the sandboxed build tool (e.g., Maven, npm), captured by the Framework, not typed by the LLM.
- **Test Results**: XML or JSON test reports generated by the testing framework (e.g., JUnit, Jest).
- **Git Diffs**: The actual output of `git diff` on the workspace, verified by the Git tool.
- **Pull Requests**: A verified GitHub PR URL.
- **Deployment IDs**: A unique trace ID from the deployment orchestrator (e.g., ArgoCD, AWS CodeDeploy).
- **Health Checks**: HTTP 200 responses from a live endpoint.
- **Security Scans**: Output from SonarQube or Trivy.

When an agent executes a tool (like `run_tests`), the Tool Sandbox captures the raw output. When the agent constructs its final `Result`, the Framework automatically injects the verified sandbox logs into the `evidence` block, preventing the LLM from hallucinating success.
