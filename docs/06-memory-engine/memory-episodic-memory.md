# Episodic Memory

Episodic memory captures the "what, where, and when" of specific events in the ForgeOS ecosystem.

## Definition
Event-oriented memory that details a specific occurrence, providing context for *why* a semantic fact might exist or *how* an error occurred.

## Examples
- "Backend deployment failed on Tuesday at 14:00 because the health check timed out."
- "The Principal Architect rejected Redis for this workload during PR review #45."
- "User Bob requested an immediate rollback of the frontend due to a visual bug."

## Characteristics
- **Owner**: Agent / Workflow
- **Scope**: Task / Project
- **Retention**: Medium-term (expires or is archived when the surrounding state is resolved or ages out).
- **Access**: Restricted to the agents involved in the workflow, or supervisory agents conducting reviews.
- **Typical Retrieval**: Root cause analysis, post-mortems, debugging, and context injection for error-recovery workflows.

## Generation
Automatically generated by the Workflow Engine and Agent Runtimes upon the completion of significant steps, failures, or explicit user interventions.
