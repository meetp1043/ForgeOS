# Semantic Memory

Semantic memory is the storage of broad, conceptual knowledge and facts. In ForgeOS, it acts as the reference encyclopedia for the project and the organization.

## Definition
Semantic memory represents factual assertions about the state of the system, business requirements, or technological environment, decoupled from the specific events (episodes) that created them.

## Examples
- "ForgeOS uses Spring Boot."
- "The project requires multi-tenancy."
- "Production deployment requires human approval."
- "The standard UI color palette is defined in `theme.json`."

## Characteristics
- **Owner**: System / Organization / Project
- **Scope**: Organization / Project
- **Retention**: Long-term (Indefinite until superseded)
- **Access**: Broadly accessible to all agents within the project scope, bounded by security classification.
- **Typical Retrieval**: Conceptual queries ("What framework do we use for the backend?"), architecture reviews, and onboarding new agents to a task.

## Generation
Semantic memories are often synthesized from Artifacts (like PRDs) or extracted over time from Conversation Memory through background summarization processes.
