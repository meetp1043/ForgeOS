# Permissions Map

Permissions follow a `RESOURCE_ACTION` naming convention.

## Organization
- `ORGANIZATION_READ`, `ORGANIZATION_UPDATE`
- `MEMBER_READ`, `MEMBER_INVITE`, `MEMBER_REMOVE`

## Project & Workspace
- `PROJECT_CREATE`, `PROJECT_READ`, `PROJECT_UPDATE`, `PROJECT_DELETE`
- `WORKSPACE_READ`, `WORKSPACE_WRITE`

## AI Agents
- `AGENT_READ`, `AGENT_CREATE`, `AGENT_UPDATE`, `AGENT_EXECUTE`

## Workflows & Tasks
- `WORKFLOW_READ`, `WORKFLOW_CREATE`, `WORKFLOW_EXECUTE`

## Approvals & Audit
- `APPROVAL_READ`, `APPROVAL_DECIDE`
- `AUDIT_READ`, `SECURITY_ADMIN`
