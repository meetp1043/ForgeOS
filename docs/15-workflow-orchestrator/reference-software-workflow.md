# Reference Software Workflow

This is the standard Software Development Lifecycle template for ForgeOS workflows:

1. **User Objective** (Trigger)
2. **Business Analysis** (PM Agent maps out the user stories)
3. **Architecture** (Architect Agent establishes interfaces and schemas)
4. **Implementation** (Parallel execution of Backend, Frontend, and Database Agents)
5. **Integration** (Wait task for Implementation to finish)
6. **QA Testing** (QA Agent generates and runs tests)
7. **Code Review** (Code Reviewer Agent checks PR)
8. **Security Gate** (Security Agent scans for vulnerabilities)
9. **Approval Gate** (Human task to approve deployment)
10. **Release** (DevOps Agent deploys to environment)
