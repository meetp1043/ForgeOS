# Summarization

Summarization is a specific compression technique that uses an LLM to distill raw text into dense, actionable context.

## Preservation Mandate

A valid summary *must* preserve:
- **Requirements**: The core objective.
- **Decisions**: Formal choices (e.g., "Use Redis").
- **Constraints**: Limits (e.g., "Must run under 100ms").
- **Interfaces**: API signatures, event schemas.
- **Risks**: Known vulnerabilities or debt.
- **Dependencies**: What this relies on.
- **Important Implementation Details**: The non-obvious "why".

## Source Referencing
Summaries are, by definition, lossy. Every summary generated by the Context Engine must include a reference to the original source (e.g., `[Summary of ADR-042. Use Tool X to read full text if required.]`). This allows the agent to recognize that it is reading a summary and gives it an avenue to fetch the missing details if its task demands it.
